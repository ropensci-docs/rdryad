# Set the 'rdryad' cache by passing a hoardr object defining cache data including local path.

Set the 'rdryad' cache by passing a hoardr object defining cache data
including local path.

## Usage

``` r
dryad_set_cache(obj)
```

## Arguments

- obj:

  A hoardr object returned from
  [dryad_get_cache](https://docs.ropensci.org/rdryad/reference/dryad_get_cache.md).

## Value

(Invisibly) The update cache object.
